Instructions Manual

Click for FAQs

Search

Use the search bar at the top to find cards by name, description, set, or image filename.

Card Details

Click a card image to view its details on the individual card page.

Account Settings

Go to User Settings to change your account information, log out, or delete your account.

Sets

Go to the "own sets" tab to create, delete, or view sets!

Adding and Removing Cards

When accessing a card's individual page from the card search page, you're given the option to add it to a selected set where it hasn't already been added (if you've made any sets). Accessing a card's individual page from your set instead provides the option to remove it from the set.

Filter System

To run the filter system, input all of the boundaries you're looking for then press the "run filter" button.
